# Pokédex

Aplicação web de uma **Pokédex**, desenvolvida com **HTML, CSS e JavaScript**, utilizando a **PokéAPI** para obter e exibir informações sobre Pokémon.

O projeto foi desenvolvido como prática de desenvolvimento frontend, integração com APIs externas e manipulação dinâmica do DOM.

🔗 **[Acessar a Pokédex](https://gustavoconce.github.io/pokedex/)**

---

## 📚 Sobre o projeto

A aplicação utiliza a PokéAPI como fonte de dados para construir uma interface de consulta de Pokémon diretamente no navegador.

O JavaScript é responsável por realizar as requisições à API, processar os dados recebidos e atualizar dinamicamente os elementos da página.

O projeto combina:

* HTML para estruturação;
* CSS para estilização;
* JavaScript para lógica e integração com a API;
* PokéAPI como fonte dos dados.

## 🔌 PokéAPI

A aplicação utiliza a **PokéAPI** para obter os dados dos Pokémon.

A API fornece informações como:

* Nome;
* Número na Pokédex;
* Tipos;
* Imagens;
* Características;
* Outras informações disponibilizadas pela API.

A aplicação realiza as requisições diretamente pelo JavaScript e utiliza os dados retornados para montar a interface.

# 🚀 Como executar localmente

## 1. Clone o repositório

```bash
git clone https://github.com/gustavoconce/pokedex.git
```

Entre na pasta:

```bash
cd pokedex
```

---

## 2. Execute o projeto

Por ser uma aplicação frontend composta por HTML, CSS e JavaScript, não é necessário instalar dependências de backend.

Uma forma simples de executar é abrir:

```text
index.html
```

diretamente no navegador.

Para uma experiência mais próxima de um ambiente de desenvolvimento, também é possível utilizar uma extensão como **Live Server** no VS Code.
